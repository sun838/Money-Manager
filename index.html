3 Cách đóng gói & Cài đặt trên Android (Gọn nhẹ)

Cách 1: Xuất file .APK tự động trên đám mây (Không cần cài Android Studio)

Tải gói so_thu_chi_android_apk.zip đính kèm bên ngoài khung chat và giải nén lên 1 kho GitHub miễn phí. File cấu hình GitHub Actions có sẵn bên trong sẽ tự động biên dịch ra file app-debug.apk chỉ sau 2 phút để bạn tải thẳng về điện thoại cài đặt.

Cách 2: Đóng gói nhanh bằng công cụ Web-to-APK 1 chạm

Dùng phần mềm miễn phí gọn nhẹ Website 2 APK Builder (trên Windows) hoặc ứng dụng WebCode / HTML2APK: Chọn chế độ Local HTML Website, trỏ tới file so_thu_chi_local.html và bấm Generate APK là có ngay file .apk chạy offline 100%.

Cách 3: Cài trực tiếp lên Màn hình chính Android trong 5 giây

Mở file này bằng trình duyệt Chrome trên Android → Bấm biểu tượng 3 chấm góc phải → Chọn Thêm vào màn hình chính (Add to Home Screen). Ứng dụng sẽ mở toàn màn hình và lưu dữ liệu vĩnh viễn trên máy.
